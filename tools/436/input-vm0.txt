# #436: get a key into cdboot's "Press any key to boot from CD or DVD" prompt.
#
# The prompt arrives later than an early fixed delay on this media. Waiting for
# the reconstructed guest screen keeps the key out of the 8042 FIFO until the
# Windows boot application is actually polling it; an early burst otherwise
# drains long before it can be consumed.
timeout 120000
expect Press any key to boot from CD or DVD.
sendkey \n
pass cdboot-key-delivered
