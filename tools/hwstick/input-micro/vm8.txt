# #542: drives tests/micro/ps2.c from outside the guest.
#
# No `expect` first: the guest is a micro-kernel, not a shell, and there is no prompt to wait for.
# A short delay instead, so the i8042 is armed before the first byte -- input sent to a controller
# whose interrupts the guest has not enabled yet is dropped by the model, and the test would then
# report "no input arrived" for a reason that is the script's fault rather than hype's.
delay 3000
sendkey A
delay 200
sendmouse 5 3
delay 200
sendmouse -2 -1 1
delay 200
sendkey B
# The script's own verdict, separate from the guest's MICRO PASS/FAIL. Without it the runner reports
# "script ended without pass/fail", which is noise in a log where the real verdict is the guest's.
pass ps2-input-delivered
